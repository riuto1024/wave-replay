WAVE-Replay V0.1 免费WEB部署（最短版本）

一、先解压本项目。

二、GitHub：
1. 登录 GitHub
2. New repository
3. Repository name：wave-replay
4. 选择 Public（免费部署最省事）
5. Create repository
6. Add file -> Upload files
7. 把解压后的所有文件/文件夹一起拖进去
8. Commit changes

三、Streamlit：
1. 登录 Streamlit Community Cloud
2. Create app / Deploy an app
3. 连接 GitHub
4. 选择 wave-replay 仓库
5. Main file：streamlit_app.py
6. Python：3.12
7. Deploy

完成后会获得一个 *.streamlit.app 的公网网址。

本项目不需要：
- 购买服务器
- 域名
- 数据库
- Binance API Key
- OpenAI API Key

本地测试：
双击 run_local.bat
